## Pièges

- Un composant enfant de `MapContainer` doit obtenir la carte par un contexte React (`useMap`), pas par une variable de module : plusieurs cartes vivent en même temps (analyse et vignette, direct et plein écran).
- Ordre d'empilement : `react-leaflet` crée les couches dans l'ordre de rendu ; garder le même ordre (fond, revêtements, trace, surbrillances, flèches, repères, repère de survol) ou poser des `pane` explicites.
- `MapAutoResize` et le plein écran : `invalidateSize` au bon moment.
- Un fichier neuf avec un style en ligne fait échouer le cliquet `inlineStyles.test.ts` : relire le total, puis `node outils/styles-en-ligne.mjs --figer`.
- `Popup` et `Marker` avec contenu React : portail (`createPortal`) vers l'élément du popup, ou contenu HTML simple si c'est tout ce qui est utilisé (l'inventaire le dira).

2. **`MapContainer`** : rend `<div className ref={attacher}>{map && <MapContext value={map}>{children}</MapContext>}</div>` ; `attacher` est une fonction de ref gardée par `useRef` (React 19 en StrictMode l'appelle deux fois) : `L.map(div)` sans option, puis `setView(center, zoom)` si les deux sont donnés sinon `fitBounds(bounds, boundsOptions)`, **puis** `setMap(map)` (TrackArrows lit `map.getZoom()` dès son premier rendu) ; `useEffect(() => () => map?.remove(), [map])`. `center`, `zoom`, `bounds` ne servent qu'à la création (HISTORIQUE point 28) ; une nouvelle trace remonte la carte par `key` ; `whenReady` employé nulle part : ne pas l'écrire.
3. **Hooks** : `useMap` lit le contexte. `useMapEvents` : gestionnaires dans une ref à chaque rendu ; clé = noms d'événements triés et joints ; un `map.on` par nom avec une enveloppe qui appelle `ref.current[nom](e)` (événement tel quel : `e.target` est la carte, lu par `MapEvents`) ; `map.off` au démontage ; rend la carte.
4. **Popup** : contenu React partout (SailingModule : `<span>`, `<br/>`, liste ; HighlightSpan : `children` ; SessionMarks : texte interpolé). `const [content] = useState(() => document.createElement('div'))`, `const [popup] = useState(() => L.popup().setContent(content))` ; effet : `parent.bindPopup(popup)` (parent de `LayerContext`, erreur s'il manque) ; démontage : `unbindPopup()` et `map.removeLayer(popup)` ; rend `createPortal(children, content)` ; `useEffect` sur `children` → `popup.update()` si `popup.isOpen()`. Une `div` détachée n'entre pas dans le texte relevé par le banc.
5. **Calques** : `Pane` crée le calque pendant le rendu (`useState(() => map.getPane(name) ?? créer)`), une fois par carte, avec son `zIndex`, jamais retiré (`map.remove()` nettoie) ; rend `<PaneContext value={name}>{children}</PaneContext>`. Ordre d'empilement identique : couche créée au rendu, ajoutée dans l'effet de la feuille ; React exécute les effets enfants avant parents, frères dans l'ordre ; une couche montée plus tard passe au-dessus, comme avant. **Interdit** : recréer une couche quand une prop change (elle repasserait au-dessus) ; seulement les `set…`.
