# Outils

- `lancer-tracker.bat` : ouvre Tracker dans le navigateur. Il démarre d'abord le serveur de développement (`npm run dev`, port 5173) dans une fenêtre réduite « Tracker - serveur » si celui-ci ne tourne pas déjà. Fermer cette fenêtre arrête le serveur. Le raccourci « Tracker » du bureau pointe vers ce fichier, avec l'icône `tracker.ico`, tirée de l'icône Android.
- `banc/` : banc de test dans un Chrome sans fenêtre (son `LISEZMOI.md`).
